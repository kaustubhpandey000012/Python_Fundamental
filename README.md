🌳 Binary Tree Traversal

One of the recent topics I practiced is Binary Tree Traversal.

Example tree:

        1
       / \
      2   3
     / \
    4   5

Preorder

Root → Left → Right

1 2 4 5 3

Inorder

Left → Root → Right

4 2 5 1 3

Postorder

Left → Right → Root

4 5 2 3 1
